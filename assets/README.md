# Recursos visuais

As ilustrações SVG em images foram desenhadas no desenvolvimento do SportZone e podem ser utilizadas neste projeto escolar. Representam modalidades/tipos de artigos; não são fotografias ou reproduções exatas dos modelos de marca do catálogo original. O banner é composição própria de quadra, bola e tênis.

As URLs de imagens do ZIP foram preservadas apenas como referência em data/products.json. A aplicação não carrega banners jornalísticos ou fotos remotas sem licença confirmada. Para fotos autorizadas, utilize o upload no painel; imagens enviadas são armazenadas em uploads com nome aleatório após verificação de tipo, tamanho e dimensões.

Bootstrap e Bootstrap Icons mantêm suas licenças upstream e são carregados nas versões CDN descritas no README. Não há vínculo comercial alegado entre este projeto escolar e as marcas citadas nos produtos originais.
